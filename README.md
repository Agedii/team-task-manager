# Team Task Manager (Менеджер задач для команд)

Упрощенный аналог Jira/Trello для управления задачами в команде.

[Демо](ссылка) · [Видео](ссылка)

![Скриншот](docs/screenshot.png)

## Возможности
- Регистрация и авторизация пользователей (JWT).
- Создание проектов и задач.
- Роли (владелец, участник, наблюдатель).
- Изменение статуса задач, дедлайны.
- Комментарии к задачам.
- История изменений (логи).

## Технологии
- **Frontend:** React — для реактивного интерфейса.
- **Backend:** Node.js + Express — для обработки API запросов.
- **База данных:** PostgreSQL (Neon) — надежное хранение реляционных данных.
- **Деплой:** Vercel (фронт) + Render (бэк).

## Запуск локально
1. Клонировать репозиторий
2. Установить зависимости (`npm install`)
3. Скопировать `.env.example` в `.env` и заполнить
4. Выполнить миграции (создать таблицы в БД)
5. Запустить проект (`npm run dev`)

## Безопасность
Пароли хешируются с помощью bcrypt. Секретные ключи хранятся в переменных окружения (.env).

## Использование ИИ-ассистентов
Использовался ChatGPT/Claude для генерации базового boilerplate-кода, настройки структуры БД и написания CSS-стилей. Весь код проверен участниками команды.
